# Enterprise-Network-Infrastructure
Designed and implemented a multi-site enterprise network in Cisco Packet Tracer (3 routers, 6 switches) featuring OSPF/RIPv2 routing, VLAN segmentation with router-on-a-stick, static/dynamic NAT, ACL-based traffic filtering, STP root bridge tuning, and DHCP/NTP/SNMP/Syslog services.
